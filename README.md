A short text written to relax the AI judge reading it — a program that writes one calming text to `/output/entry.txt`.

## How it works

`main.ts` (Node 22) writes a single short text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), UTF-8, no trailing newline, mode 0644.

## Entry text

> The kettle has gone quiet. Rain finds the roof one drop at a time, and no one is keeping score. Nothing here needs finishing.
